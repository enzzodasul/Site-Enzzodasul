## 🎧 Recursos Oficiais Integrados

1. **Player Oficial Verificado do Spotify:**
   - O player oficial do Spotify está embutido diretamente na seção de Música (`#music`).
   - Todos os botões redirecionam para o perfil verificado: `https://open.spotify.com/artist/2bl0nc1YVl0cxi5m68pMEH`.

2. **Adicionar Vídeos do YouTube por Link:**
   - Na seção **Watch** (`#watch`), clique no botão **`+ Adicionar Vídeo por Link`**.
   - Cole o link de qualquer vídeo do YouTube (seu canal ou canais de terceiros).
   - O sistema extrai automaticamente o ID do vídeo, gera a capa (thumbnail) e adiciona o card interativo na grade!

3. **Canais Oficiais:**
   - 🎵 **Spotify:** `https://open.spotify.com/artist/2bl0nc1YVl0cxi5m68pMEH`
   - 🍎 **Apple Music:** `https://music.apple.com/br/artist/enzzo-da-sul/1275587030`
   - 🔴 **YouTube:** `https://www.youtube.com/@enzzodasul`
   - 📸 **Instagram:** `https://www.instagram.com/enzzodasul/` (`@enzzodasul`)

## 📋 Passo a Passo para Executar o Projeto

### 1️⃣ Abrir o Terminal na pasta do projeto
```bash
cd "c:\app para programação\PROJETO-SITE-ARTISTA"
```

---

### 2️⃣ Instalar as Dependências
```bash
npm install
```

---

### 3️⃣ Iniciar o Servidor de Desenvolvimento
```bash
npm run dev
```

---

### 4️⃣ Abrir no Navegador
Acesse **`http://localhost:3000`** (ou a porta exibida em verde no terminal).
